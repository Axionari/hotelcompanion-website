# Read me first

Three folders, three provenances:

- **A_my-selections-from-repo-library/** — images I picked from the project's
  existing library and assigned to breather slots and page beds. This is the
  "Code chose these" set. Note: several are low-res video posters (9–25KB), not
  standalone stills.
- **B_your-batch1-retired/** — the first Pexels batch you supplied (cool/aqua
  aerials). Recovered from git history; no longer in the build.
- **C_your-batch2-live/** — the second Pexels batch you supplied (green/awe +
  warm). Currently live, plus the beach answer card derived from batch 1.

`MANIFEST.md` gives, for every file: size, exactly where it was or is placed,
current status, and the known compromises.

Nothing here is referenced by the app. It is a review copy — deleting the whole
folder cannot break the build.
